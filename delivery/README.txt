FINAL IP TECHNICAL PROTOTYPE

This package contains test content only. It does not contain the final story.

1. Extract the complete ZIP file.
2. Open index.html in Chrome or Edge.
3. Select Start prototype.
4. Select a marked area to inspect a target or change the view.
5. Select Option A or Option B to test the shared state.
6. Select Open long text to test the reading panel.
7. Select Play sound to hear a quiet test tone.
8. Select Stop to stop the tone.
9. Select Restart to clear the test selection.

Keep the assets folder next to index.html.
The package uses local files. No internet connection is required.
The long passage contains 2,500 repeated test words.
The tone is a technical audio fixture. It contains no spoken audio.
Speaker output still requires a human listening check.
All story text and final creative choices belong to the student authors.
