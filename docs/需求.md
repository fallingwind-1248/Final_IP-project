# 需求

## 已确定的项目边界

四周制作期；优先采用 Blender 预渲染图、固定镜头与点击交互。离线本机运行；交付英文作品。正文目标 2,000–3,000 词，统计口径待确认。
正式文本、选项和创意由组员人工完成。代码可以 AI 辅助。模型只能手工制作或使用获准第三方素材，禁止外包。2D 为后续备选。

## 第一版技术需求

| 编号 | 要求 |
|---|---|
| FR-01 | 两个固定视角可往返，热点与完整显示的图像一起缩放。 |
| FR-02 | 短文字和约 2,500 词测试文字进入独立阅读面板，可滚动、调字号、关闭。 |
| FR-03 | 面板打开时阻止背景交互，关闭控件保持可见，Escape 可退出。 |
| FR-04 | A/B 测试选择保存在当前游玩状态，跨视角一致；重新开始清空。 |
| FR-05 | 点击后播放本地测试音，可停止，重复点击不叠加声音。 |
| FR-06 | HTML、图片和音频整体打包，解压后双击运行，无运行时联网依赖。 |
| FR-07 | 玩家可见文字全部为英文，技术夹具有明确标记和来源。 |
| FR-08 | Twine 支持人工编辑，导出、技术修改、构建与重新导入保留正文和节点。 |
| FR-09 | Blender 可启动、保存默认场景并输出 1280×720 PNG。 |
| FR-10 | 建立本地 Git 仓库、实际记录与一个提交，由用户 push。 |

首版排除正式剧本、最终美术、配音、字幕同步、多轨混音、跨次游玩存档及多人同时编辑。
最终作品的多模态表达和有意义选择需要后续内容验收，本轮技术检查不能代替。
