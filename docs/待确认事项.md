# 待确认事项

## 正式内容阶段

1. 2,000–3,000词指总分支文本还是单次阅读量；课程通用文本参考为1,000–2,000词，游戏参考时长为5–10分钟。
2. 组员姓名、职责、选定课程主题、具体受众、核心问题与故事均待小组确定。
3. 用户已确认AI代码许可；保留课程模板原文与许可差异，后续将获得的老师说明附入事实记录。
4. 最终是否含 spoken audio 待确定；出现人声时课程要求准确同步字幕，首版测试音无人声。
5. 图像、声音和交互如何承担文字以外的意义，需在正式设计阶段论证与测试。
6. 正式第三方资产的授权、作者及来源需逐项登记。

- 听到本地测试音并确认停止有效。
