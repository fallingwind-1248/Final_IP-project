# 设计

## 数据与运行过程

作者在 Twine 修改节点 → 导出单份 Twee 源 → Tweego 使用本地 SugarCube 编译 → 拷贝白名单素材 → 浏览器通过 file:// 运行。
Twee 的 StoryData 固定格式版本和 IFID。正式文字节点使用 author-text 标签；技术代码集中在 script 与 stylesheet 节点。
正文交接检查比较标签节点的内容指纹，归一化 CRLF 并去除外围空白；它无法判断人工贡献，也不监控 Twine 尚未导出的内容。

## 交互模块

SugarCube 管理视角和当前状态；choice 使用 null、A、B。正文由阅读面板读取 TextShort 或 TextLong。
原生 dialog 管理模态层、键盘焦点和 Escape。字体范围为 16–28px。底层画面采用固定 16:9 比例，热点使用相对位置。
单个 Audio 实例共享于视角之间；播放请求有并发保护，停止会使未完成请求失效。失败在界面显示英文提示，允许再次播放。
Start 不自动播放声音。Restart 使用 SugarCube 重新开始机制清空状态并停止音频。

## 接口和替换

图片接口为 1280×720 的固定视角图。替换图像时保留素材路径，按目标位置调整对应热点百分比。
assets/manifest.json 记录每个运行素材的 path、author、source、license、modifications 和 use。构建只拷贝清单所列资产。
运行包白名单为编译 HTML、英文说明、来源说明及登记素材。构建输出与 ZIP 排除出 Git。
默认场景渲染检查独立于游戏图像，未来 Blender 渲染图和 2D 图均通过同一图片接口接入。

## 工程约束

本地工具目录排除出 Git，版本和下载指纹进入 tools.lock.json。Playwright 仅用于开发测试，运行包无需它。
不安装后端服务。浏览器运行时不请求远程字体、脚本或 API。Windows 系统字体回退不依赖下载。
采用轻量需求与验收维护；本轮不配置规格冻结、审批 Hook 或自定义代理技能。
